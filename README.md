# ⚔️ 스토리 헌터 (Story Hunter)
> 웹소설 에피소드 발굴 및 정통무협장르 치환/변환 시스템

전 세계 다양한 장르와 매체(영화, 드라마, 소설, 게임 등)의 명작 서사를 발굴하여 정통무협 웹소설 집필에 활용할 수 있는 독창적인 에피소드로 치환·축적하는 시스템입니다.

## 📌 주요 특징
1. **작품 발굴 및 추천**: 다양한 매체의 숨은 걸작을 발굴하여 스토리 요약과 추천 이유 제공
2. **에피소드 서사 요약 분석**: 기계적인 파편화 없이, 술술 읽히는 서사형 스토리 요약본 제공
3. **정통무협 사건단위 치환 (선협 100% 배제)**:
   - 도술, 선술, 영약 신선화, 강시, 환혼술 등 판타지 요소 배제
   - 구파일방, 세가, 표국, 관부, 사파, 기경팔맥, 암기, 독공 등 정통무협 문법 적용
   - 사건별 복수의 실전 치환 아이디어(방향 1, 2) 및 사이다 훅 제시
4. **Netlify 웹 대시보드 (Astryx 디자인 시스템)**:
   - 다중 선택 일괄 변환
   - 직접 작품 입력
   - Markdown / TXT 다운로드 및 아카이브 열람
5. **PC 무관 365일 자동 발굴**: GitHub Actions Cron 기반 자동화 워커 탑재
